# Alethix（探赜）Web 界面原型

一套与现有 React 工程解耦的独立静态高保真原型。用于对比视觉方向、走查信息结构与交互流程，**不调用后端接口，也不修改 `web/src`**。

## 打开方式

直接双击 `index.html` 即可在浏览器中打开；也可通过任意静态服务访问：

```bash
cd d:/workspace/book-reader
python -m http.server 4173 --directory web-prototype
# 浏览器打开 http://127.0.0.1:4173/
```

## 三套视觉方向

顶部导航右侧可即时切换，主题与演示场景会保存在浏览器 `localStorage`。

| 方案       | 名称        | 特点                                                     |
| ---------- | ----------- | -------------------------------------------------------- |
| 升级蓝灰   | `blue-gray` | 延续现有专业克制工具调性，强化信息层级与卡片质感（默认） |
| 深色研究台 | `dark-lab`  | 深色沉浸，突出证据链、状态色与调研节点高亮               |
| 纸感阅读   | `paper`     | 暖白纸张底色与衬线标题，强调原文核验场景                 |

## 演示流程

1. **文档管理**：点击「添加演示文件」或拖放本地 PDF/MD/TXT，观察 `已上传 → 解析中 → 切片中 → 向量化中 → 就绪/失败` 的状态流转。
2. **筛选与选择**：按状态筛选、搜索文件名、勾选两篇就绪文档，点击「基于选中文档发起提问」。
3. **问答调研**：在新会话中输入问题并发送，右侧时间线会逐轮出现查询、命中数、最高分与继续/收尾判定。
4. **答案核验**：展开「查看 N 条证据引用」，核对文件名、页码、章节与原文摘录；调研中可点击「停止」。
5. **会话管理**：左侧新建、搜索、切换、删除会话；窄屏可从输入框左侧按钮打开会话栏。

## 演示场景

右上角「演示场景」下拉可切换：

- `标准演示`：完整文档与会话数据。
- `空文档库`：文档列表空态与上传引导。
- `上传失败`：失败横幅、失败文档、原因展开与重试入口。
- `证据不足`：切换到证据不足的历史会话，查看警示文案与置信度。
- `调研已停止`：切换到达到最大轮次的历史会话，查看不完整结论提示。

## 目录结构

```text
web-prototype/
├── index.html                 静态外壳与脚本加载顺序
├── README.md                  本说明
└── assets/
    ├── css/
    │   ├── tokens.css         primitive → semantic → component 三层 token
    │   ├── base.css           基础排版、焦点态、减少动效
    │   └── components.css     顶栏、卡片、表格、消息、时间线、引用与响应式
    └── js/
        ├── icons.js           统一线性 SVG 图标
        ├── data.js            模拟文档、会话、调研轮次、引用与场景
        ├── store.js           轻量状态容器、主题/场景持久化
        ├── stream.js          可停止的调研过程模拟
        ├── documents-view.js  文档管理页
        ├── chat-view.js       问答调研页
        └── app.js             路由、顶栏、主题切换、全局提示与错误边界
```

## 与设计文档的关系

文案、状态语义与信息结构参考 `prd/07-frontend.md`：文档六态、会话列表、检索范围标签、逐轮调研时间线、引用折叠、置信度与 `stop_reason` 提示。字段命名对齐 `web/src/types/document.ts`、`web/src/types/session.ts` 与 `web/src/types/ask.ts`，后续如要迁移到真实接口，可直接替换 `data.js` 与 `stream.js` 的数据来源。

## 说明

- 所有数据均为本地模拟；上传只读取文件名与大小，不读取文件内容、不发起网络请求。
- 图标全部为内联 SVG，不使用 emoji 或外部图标包。
- 支持键盘焦点可见、`aria-label`、删除二次确认与 `prefers-reduced-motion`。
- 1440px 为三栏布局；1240px 以下调研区收为抽屉；920px 以下会话栏收为抽屉，表格转为卡片列表。
